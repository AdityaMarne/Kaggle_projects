# Problematic Internet Use Dataset

## Getting Started
1. Download the dataset.
   - Download data from the competition page: https://www.kaggle.com/competitions/child-mind-institute-problematic-internet-use
   - Place the dataset files in the `data/` folder.

2. Browse the data files.
   - Open the `data/` folder and review the available files.
   - The main dataset files are `train.csv` and `test.csv`.
   - There is also a `series/` folder that contains actigraphy parquet files.

3. Read the data dictionary.
   - Column names are often abbreviations.
   - The data dictionary explains what each group of columns means.
   - Examples: `BIA` = body composition, `FGC` = fitness, `PCIAT` = internet addiction test.

3. Understand the problem.
   - Review the problem statement and dataset description.
   - The goal is to predict problematic internet use (PIU) severity from physical and behavioral data.

## Useful Project Files
- `Learning/Data_Description.md` — dataset details and feature explanations.
